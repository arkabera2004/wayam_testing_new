# Parikshan 3D icon prompts

Copy-paste these into Flow, Midjourney, or Ideogram. Every prompt is built for **Parikshan** the dark AI testing command center, not generic devtool clipart.

Use them on landing feature cards, how-it-works steps, empty states, PRD analysis stages, healing events, and the command palette. Do **not** put readable text, code, selectors, URLs, logos, or company names in the render. The Lucide icons in the sidebar and tables stay; these are the dimensional marks for cards and empty surfaces.

## Color lock (use this every time)

Parikshan orange is the brand gradient carried by the mark in `public/brand/parikshan-mark.svg`. It runs light-to-deep across the diagonal.

| Role | Hex | Where it comes from |
| --- | --- | --- |
| Rim / highlight | `#FFA12B` | mark gradient stop 0 |
| Hero / body | `#FA8D23` | mark gradient stop 0.3 |
| Mid shade | `#F0731A` | mark gradient stop 0.65 |
| Recess / core | `#DC440C` | mark gradient stop 1 |
| Deep shadow | `#9A3814` | `--ref-orange-800` |
| Ember | `#431507` | `--ref-orange-950` |
| Ink (light-mode lockup) | `#121922` | wordmark fill |
| Studio void | `#000000` | `--surface-page-background` |
| Graphite body | `#101010` | `--ref-gray-950` / `--surface-container` |
| Graphite raised | `#191919` | `--ref-gray-900` / `--surface-raised` |

Do not substitute coral, amber, gold, or red. If a second material is needed, it is **dark graphite**, never a second brand color.

Status colors exist in the product (`--feedback-success-icon` `#62C487`, `--feedback-error-icon` `#FF646B`) but they belong to badges and charts. Keep them out of these renders unless a prompt below explicitly calls for a pass/fail pair.

## Style prefix (paste before every subject)

```
3D product icon, one object, centered, 1:1 square, 8k, studio key light from upper left, near-black #000000 void, no floor shadow fade, Parikshan orange gradient #FFA12B to #DC440C as the only chromatic color with #FFA12B rim light and #DC440C recesses, satin polymer with a single glass specular, crisp silhouette readable at 64px, no text, no letters, no numbers, no code, no logos, no human faces, no watermarks, no extra props
```

Then append the subject line.

## Output and placement

Render at 1024x1024, save as PNG with transparency where the tool allows, and drop them in `public/brand/icons/` using the numbered slug, for example `public/brand/icons/09-self-healing-locator.png`.

Reference them from a component the same way the brand lockup is referenced in `src/components/layout/logo.tsx`. If an icon needs to sit on a light surface later, check it against `--surface-container` in light mode (`#FFFFFF`) before shipping it, since these are all lit for a near-black void.

## What not to render

- No readable text, code, selectors, URLs, file paths, or numerals
- No GitHub, Slack, Jira, Playwright, or browser-vendor logos
- No human faces, hands, or desks
- No neon, glow, glassmorphism, or lens flare, the product design system forbids all four
- No second brand color, graphite is the only supporting material
- No Gemini sparkle or generator watermark
